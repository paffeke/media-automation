# Media Automation Scripts

Collection of personal scripts used to automate tasks in my media-server environment.

## Available scripts

* [`tracker-check`](./tracker-check/)
  Compares the local movie or TV library with a UNIT3D-based tracker.

* [`subtitle-extractor`](./subtitle-extractor/)
  Extracts Italian and English subtitles from MKV files for use as external subtitles with Emby.

Each script has its own README with requirements, configuration and usage instructions.
